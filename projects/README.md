# 프로젝트 (기획·마케팅 관점)

프로젝트를 개발 스펙이 아니라 **기획·마케팅에서 낸 가치** 중심으로 서술. 각 프로젝트의 축을 구분해 겹치지 않게 정리.

| 폴더 | 프로젝트 | 축 | 한 줄 |
|---|---|---|---|
| [`04-performance-dashboard`](04-performance-dashboard/README.md) | 마케팅 성과 대시보드 & 데이터 자동화 | **성과 측정·데이터 자동화** | 전사 KPI·예산-성과 대시보드 구축, MMP 연동 자동화, 코호트·LTV·퍼널 성과 집계 (바비톡→핸디즈) |
| [`01-sandbox-mkt`](01-sandbox-mkt/README.md) | 사내 마케팅 운영 자동화 대시보드 | **내부 도구·자동화·AI** | 마케팅팀 반복 업무를 자동화하는 사내 도구 단독 제작, AI 마케팅 에이전트 도입 |
| [`02-plott-life-frontend`](02-plott-life-frontend/README.md) | 서비스 마케팅 기능 | **콘텐츠·유입·전환** | 실서비스의 블로그 콘텐츠 운영(CMS)·SEO 검색유입·광고 전환 측정 구축 |
| [`03-plott-stay-client`](03-plott-stay-client/README.md) | Urbanstay × wavve 제휴 | **제휴 랜딩** | wavve 제휴 랜딩페이지 단독 기획·구현, 제휴 캠페인 접점 마련 |

> 축이 4개로 분리됨: **성과 측정 / 운영 자동화 / 서비스 마케팅 / 제휴**. 순서는 이력서에서 자유롭게 재배치 가능.
