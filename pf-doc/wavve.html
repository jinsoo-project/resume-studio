Urbanstay × Wavve
객실 OTT 무료 시청 · 쿠폰 발급 제휴

전국 어반스테이 객실에서 Wavve를 무료로 보고, 예약번호로 Wavve 무료 이용권까지 받아 가는 제휴 이벤트. 2026-04-21 페이지 착수 · 05-13 캠페인 시작 · 운영 중. 기획 · 랜딩 구축 · 쿠폰 발급 로직 · 리포팅 담당 (오프라인 현장 세팅 1명 · 콘텐츠 제작 1명과 협업).

결론. 웨이브와의 바터 제휴로 "전 객실 OTT 무료 시청" USP를 만들고, 랜딩 페이지 구축 · 쿠폰 발급 로직 기획 · 트래킹 · 리포팅을 직접 맡았고, 오프라인 현장 세팅과 콘텐츠 제작은 각 담당자 1명과 함께했다. 16주간 노출 503만 회(매체·자사 합산), 가이드 페이지 유입 5.8만 건, 쿠폰 7,880장을 5,413개 예약에 발급했다. 미디어 실집행은 Meta ₩250만 수준(에어브릿지 연동 기준)이고, 쿠폰 2만 장은 웨이브가 무상 제공했다. 광고비를 거의 쓰지 않고 투숙 경험에 혜택을 붙인 프로젝트다.

왜 · 무엇을 · 어떻게

왜 했나

2026년 3월 어반스테이 광고 예산이 축소된 상황에서 비용 없이 투숙 경험을 차별화할 USP가 필요했다. 웨이브는 신규 구독 유입 채널이 필요했다. 두 니즈를 바터로 묶어 투숙객에게는 객실 OTT 무료 시청과 이용권을, 웨이브에게는 체크아웃 이후 구독 전환 채널을 제공하는 구조로 설계했다.

무엇을 했나

① 투숙객 전용 랜딩 /wavve-guide를 0→1로 구축 ② 쿠폰 발급 API · DB 요구사항 설계(race-safe 발급, 1예약 4쿠폰) ③ ₩2,000만 미디어믹스 품의(Meta · Google · Naver + CRM 3채널, ROAS 300% 운영 원칙) ④ Airbridge 트래킹 체계 설계(채널 wavve_qr · 링크 11개) ⑤ BigQuery 쿠폰 현황 슬랙 자동 리포트 ⑥ 16주 협업 성과 리포트 작성.

어떻게 플레이했나

유료는 최소, 자사 접점은 최대. 체크인 알림톡과 객실 TV QR이 유입의 85%(49,902 / 58,484)를 만들었고, 유료는 네이버 브랜드검색 소재 교체(정액 범위 안)와 Meta 트래픽 캠페인 소액으로 받쳤다. 체험단 콘텐츠를 광고 소재로 재활용해 제작비를 아꼈고, 모든 진입 링크에 트래킹을 걸어 채널별 유입을 숫자로 남겼다.
